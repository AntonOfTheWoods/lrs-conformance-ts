# Archive

This directory is for non-active historical code only.

Nothing under `archive/` should be treated as a current or preferred runtime path, and no package script should point here.

Deprecated rewrite attempts are retained here under numbered directories.

- `archive/deprecated-rewrite/` contains the older proof-slice runtime.
- `archive/deprecated-rewrite3/` contains the later Bun-native rewrite attempt that has now been retired from the active root tree.
